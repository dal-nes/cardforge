❤️ Видимые трекеры — отображаются в каждом ответе

❤️ Affection / relationship meter
Numeric bar. Milestone events log to EVENT MEMORY.
🔍 Suspicion / trust meter
Inconsistencies logged to EVENT MEMORY for soft recall.
⚡ Tension meter
Unresolved tension carries forward across scene breaks.
💰 Resource / currency tracker
Items consumed on use. Good for heist, RPG, survival.
🕐 Time / countdown tracker
Time + location + optional countdown. Pairs with time skip engine.
📅 Time / date / location display
Displays at top of every response. 12-hour format. Updates on every time or location change.

🧠 Скрытые трекеры — никогда не отображаются, только пороги

🧠 Hidden intrigue tracker
How intriguing the character finds {{user}}. Surfaces through dialogue texture only.
😤 Hidden rivalry / jealousy tracker
Multi-character triangular dynamics. Jealousy decays; memory of events does not.
🛡️ Hidden guard / vulnerability tracker
Emotional availability. Drop-moments logged to EVENT MEMORY.
⚠️ Hidden danger / threat tracker
Scene stakes and pacing. Consequences persist until resolved in-scene.
🔓 Hidden relationship stage tracker
Stage tracked silently — no notifications, no display. For fully immersive bots.

🌑 Иммерсивный режим — скрытые версии видимых трекеров

❤️ Affection — hidden
Warmth and distance shown through behaviour only. No meter.
🔍 Suspicion — hidden
Wariness and openness govern tone only. No meter.
⚡ Tension — hidden
Escalation and rupture thresholds active. No meter.
💰 Resource — hidden
Loss tracked internally. Characters notice absence through narration only.
🕐 Time / countdown — hidden
Time and countdown tracked in CORE MEMORY. Urgency surfaces through narration only.
📅 Time / date / location — hidden
Tracked in CORE MEMORY. Surfaces through environmental anchors and soft recall only.

✨ Дополнительные трекеры

👑 Reputation / fame tracker
How the world sees the character. Affects NPC reactions and available choices.
🌀 Sanity / stress tracker
Mental state under pressure. Hallucinations, paranoia, or clarity thresholds.
🖤 Corruption / morality tracker
Moral decay or redemption arc. Affects choices and endings.
⚔️ Loyalty / faction tracker
Faction standing and betrayals. Shifts alliances and unlocks content.
